How a level works

  • Hidden walls

    Every level has walls, but you only see one once the robot runs into it.

  • Edge clues

    The number beside each row and column says how many walls it holds, like a Picross puzzle.

  • Robot sensor

    The robot always knows how far it is from the portal. Use that, plus the clues, to plan every move.
